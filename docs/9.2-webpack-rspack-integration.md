# 9.2. Webpack/Rspack Integration

Use this path when your organization already standardizes on Webpack or Rspack.

This page configures Webpack or Rspack to compile the same Valyrian TSX entry for development and production.

## Recipe Contract

Objective: compile one Valyrian.js TSX entry through Webpack or Rspack.

Starting point: an application that needs explicit bundler configuration and one stable render target.

Files:

- `tsconfig.json` sets the automatic TSX runtime.
- `index.html` supplies the document template.
- `src/main.tsx` imports `mount` and renders the app.
- `webpack.config.cjs` or `rspack.config.cjs` carries the selected bundler transform.
- `package.json` exposes the selected dev and build scripts.

Run or verify: execute only the selected branch first, either `npm run dev:webpack` plus `npm run build:webpack` or `npm run dev:rspack` plus `npm run build:rspack`.

Observable result: the selected bundler serves and builds the same entry without JSX transform errors.

Continue: use [Taskboard Stage 2](./taskboard-tutorial.md#stage-2-add-interaction-with-pulsestore) after first render works, then add routing or state inside the same entry.

Prerequisite:

- [./3.1-runtime-core.md](./3.1-runtime-core.md)

## Goal

1. Compile TSX with Valyrian runtime.
2. Run local dev server.
3. Build a production bundle with the same transform assumptions.

## Install

```bash
npm i valyrian.js
npm i -D typescript
```

Create `src/main.tsx`:

```tsx
import { mount } from "valyrian.js";

function App() {
  return (
    <main style="font-family: sans-serif; padding: 2rem;">
      <h1>Valyrian Bundled App</h1>
      <p>Webpack/Rspack integration is working.</p>
    </main>
  );
}

mount("body", App);
```

## TypeScript JSX Settings (Required)

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "valyrian.js"
  }
}
```

## Webpack Recipe

Install:

```bash
npm i -D webpack webpack-cli webpack-dev-server ts-loader html-webpack-plugin
```

`webpack.config.cjs`:

```js
const HtmlWebpackPlugin = require("html-webpack-plugin");

module.exports = {
  mode: process.env.NODE_ENV || "development",
  entry: "./src/main.tsx",
  devtool: "source-map",
  resolve: {
    extensions: [".tsx", ".ts", ".js"]
  },
  module: {
    rules: [
      {
        test: /\.[tj]sx?$/,
        exclude: /node_modules/,
        use: {
          loader: "ts-loader",
          options: {
            transpileOnly: true
          }
        }
      }
    ]
  },
  plugins: [new HtmlWebpackPlugin({ template: "./index.html" })],
  devServer: {
    port: 5173,
    historyApiFallback: true
  },
  output: {
    clean: true,
    filename: "assets/app.js"
  }
};
```

Scripts:

```json
{
  "scripts": {
    "dev:webpack": "webpack serve",
    "build:webpack": "webpack --mode production"
  }
}
```

## Rspack Recipe

Install:

```bash
npm i -D @rspack/core @rspack/cli @rspack/dev-server
```

`rspack.config.cjs`:

```js
const { rspack } = require("@rspack/core");

module.exports = {
  mode: process.env.NODE_ENV || "development",
  entry: "./src/main.tsx",
  resolve: {
    extensions: [".tsx", ".ts", ".js"]
  },
  module: {
    rules: [
      {
        test: /\.[tj]sx?$/,
        exclude: /node_modules/,
        loader: "builtin:swc-loader",
        options: {
          jsc: {
            parser: {
              syntax: "typescript",
              tsx: true
            },
            transform: {
              react: {
                runtime: "automatic",
                importSource: "valyrian.js"
              }
            }
          }
        }
      }
    ]
  },
  plugins: [new rspack.HtmlRspackPlugin({ template: "./index.html" })],
  devServer: {
    port: 5174,
    historyApiFallback: true
  },
  output: {
    clean: true,
    filename: "assets/app.js"
  }
};
```

Scripts:

```json
{
  "scripts": {
    "dev:rspack": "rspack serve",
    "build:rspack": "rspack build --mode production"
  }
}
```

## Verify

```bash
npm run dev:webpack
npm run build:webpack
npm run dev:rspack
npm run build:rspack
```

Observable result: the selected bundler renders the same app and completes the production build without JSX transform errors. Run both branches only when the project needs parity between Webpack and Rspack.

## Key Points

Required for correctness:

1. Keep `jsxImportSource` / bundler `importSource` aligned with `valyrian.js`.
2. Keep TypeScript and bundler runtime settings in sync across Webpack and Rspack.

Recommended practice:

1. Keep one stable mount root (`#app` or `body`) across bundler targets.
2. Keep parity checks between Webpack and Rspack output behavior before release.

## Practical Baseline

Start with one entry file and one render target, then add code-splitting or advanced plugin chains after first render works.
